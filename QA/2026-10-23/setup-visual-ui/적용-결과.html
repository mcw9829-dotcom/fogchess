FOGCHESS · UI UPDATE · 2026.10.23

글 중심의 배치 카드를
한눈에 읽히는 준비 화면으로

로컬 Godot 적용 완료. 기존 Material 모션과 체스판·기물 디자인은 유지했습니다.

바뀐 점

  • 내 진영 3줄을 작은 도식으로 보여주고, 조작 안내는 ‘기물 선택 → 놓을 칸 선택’으로 줄였습니다.
  • 기본 배치·무작위는 같은 크기의 아이콘 버튼으로, 준비 완료는 체크 아이콘을 가진 주 버튼으로 정리했습니다.
  • 소리는 아이콘과 상태별 도움말을 사용합니다. 기권·나가기는 구분선 아래에 두고 글자를 유지했습니다.
  • 서버에서 준비 완료를 확인하면 도식이 체크로 바뀝니다. 준비 취소 시 배치 안내로 돌아옵니다.
  • 대국이 시작되면 배치 안내는 사라지고 기존 행동 안내가 복원됩니다.

검증

배치·준비·취소·소리를 임시 로컬 서버에서 검증했습니다. 320px·390px 화면에서 버튼 폭과 접근 가능한 이름, 44px 소리 버튼 영역을 확인했습니다. 보드·기물·지형 등 보호 파일 328개는 해시가 동일합니다.

검사 결과: 배치 카드 20 · Material 32 · 보드 UI 128 · 기존 UX 58 · 통합 255 (총 493개 통과).

모바일 검증은 데스크톱의 창 크기 조정으로 진행했습니다. 보드·기존 UX 검사 종료 시 ObjectDB 2개 정리 경고가 각각 남았으며, 스크립트 오류는 없습니다. 웹 빌드·운영 배포는 하지 않았습니다.
