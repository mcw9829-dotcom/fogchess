UI·UX 개선안 8개 적용 완료

바탕화면 Fogchess의 로컬 Godot 소스에 반영했습니다. 체스판·기물·지형 디자인과 서버의 게임 규칙을 유지하면서 안내·동선·학습·기록·확인 절차를 개선했습니다.

01 · 학습 정합성튜토리얼 나이트 시야를 서버와 같은 반경 2로 수정. 기존 3단계 미션 완료와 시야 경계 확인.
02 · 행동 안내현재 가능한 행동과 재장전 규칙 분리. 기물·좌표·행동을 표시하고 “행동 바꾸기”와 터치 취소 안내 제공.
03 · 모바일 시간원래 시계가 스크롤 밖으로 나가면 시간과 “보드로” 버튼 표시. 한 번에 복귀하며 선택 상태 유지.
04 · 기권 결정기권 계열의 위험색 통일. 결과 화면에 남기와 홈 이동을 구분. 확인창은 취소에 기본 포커스, 취소하면 메뉴 복원.
05 · 첫 대국홈의 직접 학습 진입, 완료 후 쉬움 봇 연결. 인트로의 학습/바로 시작 선택지와 현재 배치로 준비 완료 안내.
06 · 상태 해석선택 기물 노출과 내 전체 노출 수 구분. 컴퓨터·혼자 연습에서 안개/노출/재장전 상황 안내. 끄기와 설정에서 다시 켜기 제공.
07 · 조작성보드 바깥 주요 아이콘 44×44 논리 단위. 도움말에서 행동 설명·선택·취소 접근, Esc 닫기와 포커스 복귀. 시간 경고 등 의미가 바뀔 때만 접근성 알림.
08 · 기록·응답·결과최근 3건은 유지하고 받은 교전 기록 펼치기 추가. 느린 요청과 결과 미확인 구분, 중복 행동 차단. 이번 판/시리즈 결과와 다음 판 문구 구별.

적용 화면

현재 소스와 임시 서버 테스트 상태를 실제 Godot으로 렌더링했습니다. 테스트마다 지형이 달라질 수 있으며 그래픽 에셋은 변경하지 않았습니다.

  • Godot 통합 검사 256개: 학습·실제 봇 응답·배치·능력·채팅·기보·관전·매칭·시리즈 등.

이전 검토용 캡처의 봇 응답 실패는 Windows의 자식 프로세스 시작 시 캡처 래퍼가 다시 실행되는 문제였습니다. 실행 진입점을 보호한 뒤 전체 검사에서 봇 응답이 통과했습니다. 게임 서버의 봇 규칙은 변경하지 않았습니다.
