Fog Chess — 결함 4건 및 공통·대국 UI 수정 결과
2026-10-21

수정한 결함
G01: 킹을 죽인 공격자가 아닌 죽은 킹의 반대 진영을 승자로 결정.
- 아군/적군 킹 피격, 백/흑, 양 킹이 같은 사격선인 경우 테스트 6개.
- 첫 킹 사망에서 사격 종료. 종료 후 턴 마감시각 제거.
G02: 비랭크 배치 단계의 빈 좌석만 신규 배정. 끊긴 기존 참가자 좌석 회수 제거.
- 진행중/랭크 좌석 보호. 원 토큰/동일 계정의 새 세션으로 복귀 가능.
- 재접속 요청의 계정 정보로 기존 좌석 identity를 덮어쓰지 않음.
G03: 계정 ID당 매칭 대기 하나. 세션 변경 시 기존 대기/수락 상태를 이전.
- queue TTL과 별도로 진행 중 대국을 확인해 기존 랭크 방으로 복귀.
- 다른 대국 진행 중 중복 방 생성/매칭 우회도 차단.
G04: game_settlements 추가 테이블에 경기 ID별 정산 결과 저장.
- 레이팅/양쪽 전적/정산 원장을 한 트랜잭션으로 저장. 성공 후에만 완료 표시.
- DB 오류/commit 후 응답 유실 시 같은 경기 ID로 재시도해 중복 지급 방지.
- 저장 실패 중 재대결은 기존 결과를 유지하며 거부. 미정산 종료방 TTL 삭제 방지.
- 참가자 결과 화면에 '결과 저장 중 · 자동으로 다시 시도합니다' 표시.
- 한계: DB 장애 도중 서버 프로세스 자체가 종료되는 경우 메모리에 남은 미저장 대국 복구는 별도 영속화 과제.

UI 변경
- primary/secondary/tertiary/danger 버튼 역할 API. 기본 높이 42, 글자14, 반경9.
- hover/pressed/focus/disabled 상태와 다크/밝은 테마 적용 일관성.
- 차례/큰 타이머/턴 수/시리즈 점수/경고를 분리. 타이머 세로 줄바꿈 방지.
- 대국 우측 패널: 기록 영역만 스크롤, 채팅 입력은 별도 하단 영역에 유지.
- 이동 기록은 최근 4수, 전체 기록은 버튼으로 열람. 상대 기보 비공개 정책 유지.
- 킬로그 유지, 빈 포획 목록 중복 설명 축약. 기권 등 내부 이벤트명을 사용자 문구로 변환.
- 결과: 승패·시리즈 점수에서 나/상대 구분, 대표 버튼 강조, 리플레이는 보조 행동.
- 중복 재대결/종료 조작 제거. 정산 대기 표시.
- 리플레이 재생 컨트롤 높이는 실제 버튼 크기에 맞춰 자동 계산.
- 웹 순위표의 승패 텍스트 세로 줄바꿈 보정.

변경하지 않은 것
- 체스판 렌더 코드, 기물 에셋, 숲/부쉬 에셋 및 지형 규칙은 변경하지 않음.
- 방/기보 데이터를 지우거나 기존 회원/전적을 초기화하지 않음.
- IME 문제는 미해결 backlog로 유지. 추가 엔진 작업 없음.
- Fly.io 배포 없음. 기존 사용자 게임/개발 서버 프로세스는 재시작하지 않음.
- 실행 중인 서버와 Godot은 재시작해야 새 서버 코드/네이티브 UI가 적용됨.

검증
- python -m pytest -q: 161 passed, 12 subtests passed.
- Godot 주 통합 검사: GODOT_SMOKE_FAILURES=0.
- 실제 렌더 캡처: 1280x720 대국/결과 및 390x844 좁은 화면.
- 긴 80수 기보에서 4수 미리보기/전체 열기, 채팅 입력 영역 유지 검사.
- 실제 타이머 줄바꿈 결함을 캡처로 발견 후 수정하고 단일행 회귀검사 추가.
- 리플레이 25개/관전 17개 통과. 관전 종료 시 기존 ObjectDB 2개 누수 경고는 남음.
- 로컬 웹 내보내기 성공, 웹 호스트 7개 검사 통과.
- 브라우저의 localhost Godot 빌드에서 홈/안내/게스트 혼자 연습 UI 렌더 확인.
- 브라우저 테스트는 기존 실행 중 개발 서버를 사용하므로 신규 서버 보호 로직 검증은 임시 서버의 자동 HTTP 검사로 수행.
- 실제 모바일 기기/네트워크 장애 실환경/한글 IME 해결 검증은 포함하지 않음.
