대국 화면 정보 그리드 · 2026-10-21

사용자 지적
상단 제목/메뉴, 관전자, 상태/타이머, 상대 정보에 공통 구획이 없어 개발 중 화면처럼 보임. 이전 UI·UX QA가 개별 요소 위주로 검토하고 화면 전체 정렬 일관성을 놓친 항목.

적용
- 상단 하나의 패널에 제목·메뉴 / 상태·시간 / 상대·관전자 3행. 내부 가로·세로 구분선과 공통 패딩.
- 상대 이름과 레이팅을 분리해 긴 이름을 줄여도 점수와 관전자 수를 유지. 전체 이름은 툴팁으로 제공.
- 시리즈·시간 경고 공간 예약. 종료된 타이머는 중립색으로 낮춤.
- 보드 아래 내 정보와 관전 뒤집기 버튼을 같은 정보 패널에 배치.
- 리플레이 시야 선택과 재생 조작부도 패널로 구획. 재생 조작은 계속 보드 아래.
- 관전자 row를 다른 부모의 자식 인덱스에 끼워 넣던 코드를 명시적 슬롯으로 수정.
- 실제 표시 높이로 데스크톱 보드 영역을 계산해 관전 알림이 있어도 하단 선수 정보가 잘리지 않음.
- 모바일은 세로 공간 부족 때문에 보드 가로폭까지 줄이지 않고 페이지 스크롤을 사용.
- 봇전·관전 등 채팅 불가 상태에서 비어 있는 채팅 바깥 패널까지 숨김.
- 밝은 테마의 안내 문구 대비 개선.

하위 UI·UX 에이전트 검토
구획/정렬/정보 묶음/모바일/긴 이름/복합 상태 기준으로 재검토 요청. 최초 검토에서 빈 채팅 패널과 종료 타이머 강조를 지적했고 모두 수정.
최종 실제 캡처 6개 검토에서 요청 범위의 명확한 배치 결함 없음.
검토 범위: PC 대국/관전, 390px 긴 닉네임+최종전+7초 경고, 320px 및 밝은 테마, 모바일 리플레이.
시각 검토와 별도로 부모 에이전트가 대국·채팅·재대결·관전·리플레이 자동 실행 검사를 수행.

유지
체스판 타일/기물/숲/부쉬 에셋 변경 없음. 게임 규칙·회원 DB 변경 없음. 사용자 실행 중 서버·게임 강제 재시작 및 Fly.io 배포 없음.
