Fog Chess 통합 QA — UI·UX / 게임성 / 출시 품질
검토일: 2026-10-21

목적과 범위
- 하위 에이전트 3명: 시각 디자인, UX 흐름, 게임 규칙·밸런스 검토.
- 목표: Fly.io에 올릴 웹 게임의 완성도를 높이기 위한 개선 목록. 이번에는 구현하지 않음.
- 변경 제외: 체스판/체스 보드/숲/부쉬. 기물 에셋, 기물 행동 아이콘 팬과 호버, 킬로그의 기본 방향도 유지.
- 사용자의 한글 입력 재시험은 실패. 미해결 항목으로 유지하고 엔진 변경을 추가 진행하지 않음.
- 읽기 전용 코드 조사, 기존 1280x720 캡처 2장, 독립 메모리 재현 및 관련 회귀검사.
- 마우스·키보드 UI 조작, Fly.io 배포, 운영 DB 변경 없음.
- 한계: 이번에 전체 화면을 실제 브라우저에서 새로 플레이하지 않았음. 모바일 실기기, 실제 참가자 승률/이탈률 데이터 없음.
- 예전 QA 문서는 참고 자료이며 수정 완료된 과거 결함을 현재 결함으로 재등록하지 않음.

판정 기준
P0: 출시 전 막아야 하는 승패/참가자 권한 결함.
P1: 신뢰성 또는 주요 플레이 흐름/시각 위계에 큰 영향.
P2: 완성도, 일관성, 보조 화면 개선.
확인된 구현/재현과 디자인 의견/밸런스 가설을 구분함.

총평
보드 에셋의 문제가 아니라 주변 UI가 기능 추가 순서대로 세로로 쌓인 것이 핵심이다.
모든 버튼이 비슷한 회색 캡슐이고, 작은 설명문과 같은 무게의 카드가 반복되며,
대국 종료·로딩·기록 같은 상태가 여러 위치에 나뉘어 있다. 이는 시각 QA의 평가이며
사용자 연구로 측정한 결과는 아니다. 새 일러스트를 늘리기보다 정보의 우선순위부터 정리한다.

보존할 강점
1. 기물에서 펼쳐지는 행동 선택, 애니메이션과 호버.
2. FPS 방식 킬로그와 잡은 기물 아이콘.
3. 기존 보드/기물/숲/부쉬 스타일과 은폐 표현.
4. 리플레이의 위쪽 시야 전환과 아래쪽 재생 조작.
5. 관전 3분 지연과 관전자 수, 무승부를 승수에 넣지 않는 2선승 재대결 규칙.

제안하는 화면 구조
로비: 브랜드·프로필 → 주요 플레이 → 친구 플레이 그룹 → 기록·관전. 순위는 보조 영역.
배치: 배치 시간 → 기본/무작위 보조 버튼 → 큰 준비 완료. 방 정보·초대는 별도 정돈.
대국: 차례·시간 HUD + 플레이어 헤더 → 기존 보드 → 오른쪽 행동 안내/킬로그/축약 기록/고정 채팅.
결과: 승패/점수/레이팅 → 대표 행동 하나 → 리플레이/홈 보조행동.
관전·리플레이: 기존 보드 및 시야/재생 위치 유지, 상태와 도구의 위계만 정리.

진행 순서 제안
0. 출시 차단 승패·좌석 권한 오류와 정산 신뢰성부터 수정, 재현 테스트를 회귀 검사에 추가.
1. 공통 버튼·타이포·간격·문구 규격, 대국 HUD/우측 패널/결과 화면 정돈.
2. 로비·친구 참가·회원가입·관전·리플레이의 진입 흐름 정돈.
3. 최종 웹 빌드로 여러 화면 크기와 실제 사용자 플레이 검증. 밸런스는 지표 수집 후 조정.
신규 기능을 늘리거나 보드 에셋을 다시 만들지 않고 기존 기능의 발견성·일관성을 개선한다.

출시 확인 체크
- 승패/좌석 권한/정산 결함 재현 차단 및 회귀 검사.
- 1280x720, 1920x1080, 좁은 웹 화면에서 긴 이름/긴 기보/많은 채팅을 넣어 검증.
- 키보드 포커스, 터치, 브라우저 탭 복귀, 지연/끊김/재접속 확인.
- 한국어/영어 입력·수정·전송은 실제 OS IME로 별도 확인. 완성 문자열 삽입 시험으로 대체하지 않음.
- 모바일/플레이어 대전/접근성 검증은 아직 완료로 간주하지 않음.

G02 / P0 / 경기 중 끊긴 좌석을 제3자가 가져갈 수 있음
