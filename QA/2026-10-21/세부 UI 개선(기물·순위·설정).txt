Fog Chess 개발 UI 후속 개선 · 2026-10-21

적용 내용
- 기물 설명: 재생 중인 카드에 밝은 금색 외곽선과 ‘재생 중 · 행마/공격/능력’ 표시. 다른 카드 재생 시 이전 표시 해제. 모바일 기물 버튼도 시연 시작.
- 기물 선택: 칸의 노란 사각선과 보드 전체 턴 발광을 제거하고, 선택한 기물의 윤곽만 강조. 턴 정보는 상단 HUD에서 표시.
- 외곽선은 기존 기물 이미지 알파로 만든 외부 스트로크를 캐시하며, 기물 내부를 덮지 않음. 부쉬의 전경 배치와 기물 투명도 유지.
- 리더보드: 순위/티어/플레이어/전적/레이팅의 5열 격자와 헤더, 가로·세로 구분선. 티어 사다리도 개별 카드로 구분. 모바일에서는 티어를 3열로 배치.
- 설정: 선택한 테마에 체크 표시와 강조색 적용. 토글에 켜짐/꺼짐 텍스트. 색약 모드에 실제 보드의 이동 점/공격 원/스캔 사각 표시 및 적용 색상 미리보기.
- 테마 결함 수정: 이미 열린 설정 카드의 어두운 배경이 화이트 전환 후 남던 스타일 오버라이드를 갱신.

유지 범위
- 체스판 타일 색, 기물 원본 에셋, 숲 및 부쉬 에셋, 피드백 폼은 변경하지 않음.
- 규칙, 서버 데이터베이스, 계정 비밀번호, 관리자 키를 변경하지 않음.
- Fly.io 배포 및 실행 중인 사용자 개발 서버/게임의 강제 재시작 없음.

검증
- 격리된 임시 DB/HTTP 서버를 사용하는 Godot 실렌더링 통합 검사: 232개 PASS, GODOT_SMOKE_FAILURES=0. 스크립트 오류 및 경고 없음.
- PC 1280×720 / 모바일 390×844 크기에서 기물 설명·설정·순위표 확인.
- 화이트 전환 후 기존 카드 배경 갱신, 테마 단일 선택, 색약 팔레트 적용, 카드 재생 전환 및 단계 표시 확인.
- 캡처: .dev-data/qa-captures/{guide,guide_mobile,action_menu,settings,settings_light,settings_mobile,leaderboard,leaderboard_mobile}.png
- 로그: .dev-data/ui-detail-smoke.log

인증 구조 확인
- 일반 회원 계정은 salt + PBKDF2 해시로 비밀번호를 저장. 기존 문자열 복원이 아닌 복구 코드 기반 재설정 사용.
- 관리자 화면은 일반 회원 아이디와 별도로 서버 환경 변수 FOG_ADMIN_KEY를 검사. 키 값 자체는 이번 작업에서 출력하거나 변경하지 않음.
