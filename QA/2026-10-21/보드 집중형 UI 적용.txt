2026-10-21 · 보드 집중형 UI 개발 적용

선택한 시안: fogchess-match-ui.html / 보드 집중형.

적용
- 선으로 나눈 대국 헤더를 제거하고 차례·시간 배너와 얇은 시간 막대로 변경.
- 상대 이름·레이팅·시리즈 점수는 보드 위, 내 정보·관전자 수는 보드 아래.
- 대국 메뉴·도움말·음향은 상단의 작은 도구 버튼으로 통합.
- 선택한 기물의 아이콘·좌표, 행동 안내, 규칙 펼침·취소를 한 카드에 배치.
- 행동 아이콘 간격을 시안에 맞추고 마우스 호버/키보드 포커스로 설명과 합법 범위 미리보기.
- 미리보기는 행동 선택을 하지 않으므로 대상 칸만 눌러서는 턴이 실행되지 않음.
- 화면 크기/안내 높이 변경 시 행동 아이콘이 닫히지 않고 기물 위치에 재배치됨.
- FPS 킬로그와 잡은 기물 에셋 유지, 최근 교전 3건 표시, 밝은 테마 배경 수정.
- 기보: 최근 3수 한 줄, 펼침 최근 10수, 전체 기록은 기존 창으로 연결.
- 채팅은 새 방에서 접힌 상태로 시작, 읽지 않은 메시지 수 유지. 펼친 입력칸은 기록 스크롤 밖에 고정.
- 전용 구현: godot/features/match_ui(대국 HUD·행동 안내·기보).gd

보존
- 체스판 렌더러, 기물·숲·부쉬 원본 에셋, 규칙과 Python 서버 코드 변경 없음.
- Fly.io 배포와 운영 DB 접근 없음.
- 네이티브 한글 IME 문제는 기존 개선 항목으로 유지.
