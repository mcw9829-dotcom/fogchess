# 안개전장 체스 (WW1 Fog Chess)

체스 구조를 빌린 안개(포그 오브 워) 전략게임. 배틀쉽처럼 서로 맵을 가리고,
숨긴 킹을 찾아 처치한다. 로컬에서 서버를 켜고 같은 와이파이의 친구와 2인 대전.

## 실행

`fogchess` 폴더에서:

```bash
python server.py
```

1. 나: 브라우저에서 `http://localhost:<포트>` 접속 → **방이 자동 생성**되고 내가 백(아래)
2. 화면 좌측의 **"🔗 친구 초대 링크"** 를 [복사] 해서 친구에게 전달
3. 친구: 같은 와이파이에서 그 링크(`http://192.168.x.x:<포트>/#방코드`)로 접속 → 흑(위)

> 포트 번호는 서버 시작 시 터미널에 출력됩니다(`server.py` 상단 `PORT` 값, 현재 7555).

**혼자 테스트(핫시트)**: 친구 없이 혼자 모든 기능을 시험하려면, 시작 화면(상대 대기 중)에서
**[🧪 혼자 테스트]** 버튼을 누르세요. 한 화면에서 양쪽을 번갈아 조작하며(차례가 바뀌면
시점도 바뀜), 배치 없이 바로 전투로 시작합니다. **[🌫 전체 보기]** 토글로 안개를 껐다 켤 수
있어(디버그) 기물 움직임을 한눈에 확인할 수 있습니다.

**방(room) 시스템**: 여러 쌍이 동시에 각자 다른 방에서 플레이할 수 있습니다(방코드로 구분).
- **재접속**: 실수로 창을 닫거나 새로고침해도 같은 링크로 들어가면 원래 자리로 복귀.
- **재대결**: 게임이 끝나면 결과 화면의 **[↻ 재대결]** 또는 좌측 **[↻ 새 게임 / 재대결]** 버튼.
- **무한게임 방지**: `TURN_LIMIT`(기본 200)턴까지 승부가 안 나면 무승부.
- 상대가 오래 응답 없으면(15초+) 그 자리는 새 접속자가 회수할 수 있습니다.

## 규칙 요약

- 맵 12×12, 기물 14개: 룩2·나이트2·비숍2·폰7·킹1 (퀸 없음)
- **배치 단계 60초**: 자기 진영 3줄 안에서 기물을 클릭해 옮겨 배치 → [준비 완료]
- 시야: 대부분 반경 1칸, **나이트만 2칸**(정찰). **산이 시야를 막음**(LOS)
- 폰: 첫수 2칸 · 앞·좌·우·앞대각 1칸 · **후퇴 불가**
- 나이트/킹: 체스와 동일
- **비숍(야포)**: 대각 2칸 이동 / **곡사 포격** — 맵 전체·X자 5칸·**산 넘김**
- **룩(전차)**: 상하좌우 3칸 이동 / **돌파 사격** — 직선 3칸 관통·**산에 막힘**
- 비숍·전차는 **공격하면 내 위치·주변이 적에게 노출**(역공 위험)
- 킹 **목숨 1** — 한 번 맞으면 처치, 그쪽이 승리

## 맵/밸런스 직접 수정하기

모든 튜닝값은 **`config.py`** 한 파일에 모여 있습니다. 여기만 고치면 됩니다.

### 지형(산) 편집

`config.py`의 `MAP_ROWS` 는 12줄 × 12칸의 그림 지도입니다. `#` = 산, `.` = 빈 땅.
그림 그리듯 `#` 위치만 바꾸면 맵이 바뀝니다. (단 `USE_PERLIN = True`면 자동 생성이
우선이라 무시됩니다. 수동 맵을 쓰려면 `USE_PERLIN = False`.)

```python
MAP_ROWS = [
    "............",   # 0  (흑 배치 구역 — 비워두기)
    "............",   # 1
    "............",   # 2
    "..##....#.#.",   # 3   <- 이런 식으로 # 를 옮기면 산 위치가 바뀜
    ...
]
```

- 맨 위 3줄 / 맨 아래 3줄은 **배치 구역**이라 비워두세요(산 두면 무시됨).
- 양쪽이 공평하도록 상하·좌우 대칭으로 그리는 걸 추천.
- 산은 시야·이동을 막고, **전차 직사는 막지만 비숍 곡사 포탄은 넘어갑니다.**

### 강 (`USE_RIVER`, `RIVER_MODE`)

강 = **해자**. 산과 반대로 **시야·사격은 통과하지만 못 건넌다**(이동·배치 차단). 나루터(gap)로만 도하.
- `RIVER_MODE`: `'random'`(매 맵마다 가운데/양사이드 랜덤) · `'center'`(가운데 가로) · `'sides'`(양쪽 세로) · `'none'`
- 산: 시야·이동·전차 직사 모두 차단(곡사만 넘김) / 강: 이동만 차단, **전차 직사·비숍 곡사·시야는 전부 통과**

### 산 대칭/비대칭 (`MAP_SYMMETRY`)

펄린 자동생성 시 맵의 대칭 방식을 고릅니다:
- `rotational` — 180° 회전 대칭 (완전 공정, 기본값)
- `mirror` — 상하 거울 대칭 (완전 공정)
- `balanced` — 모양은 비대칭이지만 위/아래 산 개수 동일 (**공정+다양성, 추천**)
- `free` — 완전 랜덤 비대칭 (다양성 최대, 한쪽에 쏠릴 수 있음=맵빨)

### 숫자 밸런스 편집

같은 구역의 상수:

| 값 | 의미 |
|---|---|
| `VISION` | 기물별 시야 반경 (나이트만 2) |
| `KING_LIVES` | 킹 목숨 |
| `ROOK_RANGE` | 전차 이동/돌파사격 최대 칸 |
| `BISHOP_MOVE` | 비숍 대각 이동 최대 |
| `SETUP_SECONDS` | 배치 제한 시간(초) |
| `MUZZLE` | 공격 후 위치 노출 지속(턴) |

**수정 후에는 서버를 재시작해야 반영됩니다** (Ctrl+C → `python server.py`).

## 파일 구성 (역할별로 분리됨)

- **`config.py`** — 모든 설정값(포트·맵·밸런스·타이머). **튜닝은 여기만.**
- **`game_map.py`** — 맵/지형: 펄린 노이즈 산 생성, 시야 차단(LOS).
- **`pieces.py`** — 기물/규칙: 행마·이동·포격·돌파사격·킬로그·안개 뷰(`player_view`).
- **`server.py`** — 서버/네트워크: 방·재접속·HTTP. 규칙은 pieces에 위임.
- `client.html` — 브라우저 화면(보드·기물·사운드·이펙트·킬로그).
- `img/` — Lichess(cburnett) 체스 기물 SVG.

의존 방향: `config` ← `game_map` ← `pieces` ← `server` (한 방향, 순환 없음).

## 먼 곳의 친구와 하려면

같은 와이파이가 아니면 LAN만으론 안 됩니다. `ngrok` 같은 터널이 필요해요
(필요하면 방법을 따로 안내).
