# 안개전장 체스 (Fog Chess)

체스 구조를 빌린 **안개(포그 오브 워)** 전략게임. 서로 맵을 안개로 가리고, 정찰로 적을 찾아
**숨긴 킹을 처치하면 승리**한다. 로컬 서버를 켜서 같은 와이파이 친구와 2인 대전하거나,
**컴퓨터(AI)** 와도 붙을 수 있다.

## 실행

`fogchess` 폴더에서:

```bash
python server.py
```

- 브라우저에서 `http://localhost:7555` 접속 → **시작 메뉴**가 뜬다. 여기서 무엇을 할지 고른다:
  - **⚔️ 첫 접속 인트로(≈1분)** — 슬라이드 4장(배치: 매 판 새 맵, 70초 동안 내 진영 3줄에 자유 배치·왕 숨기기 / 시야: 전진하면 숨은 적이 드러남 / 지형: 부쉬 매복, 같은 덤불에 들어오면 서로 보임, 숲 벽 / 목표: 퀸 스캔으로 왕을 찾아 비숍 저격) → [컴퓨터(쉬움)와 첫 판 두기]. 장면마다 3.2~4.8초 머묾(자막 읽을 시간). 규칙 설명은 이 인트로 한 곳 — 게임 화면 [❔ 규칙]과 기물 설명 창의 '처음 안내(1분) 다시 보기'로 재생.
  - **📖 기물 설명** — 사이드바에서 기물별 행마 → 공격 → 능력 애니메이션(카드에 마우스/탭). 규칙 카드 8장은 v1.49에서 제거(인트로로 통합).
  - **📜 패치노트** — 사이드바 로고 아래 `v1.xx · 패치노트`(또는 헤더 배지)를 누르면 이 파일(패치노트.txt)을 파싱한 변경 이력 모달. GET /patchnotes.
  - **📊 최근 전적** — 프로필에 최근 20판(상대·결과·종류·레이팅 변동·종료 사유·시각)과 레이팅 변화 그래프. 게임이 끝날 때 회원 좌석마다 기록(`games` 테이블, POST /me/history).
  - **🎖️ 계정** — 닉네임 + 비밀번호(8자 이상 · 영문+숫자+특수문자 각 1개 이상). 가입 완료 때 **복구 코드**(FOG-XXXX-XXXX, 해시로만 저장)를 한 번만 표시. 로그인 창 [비밀번호나 닉네임을 잊었나요?] → 복구 코드로 새 비밀번호(닉네임도 알려줌 · 다른 기기 로그아웃 · 코드는 1회용이라 새 코드 발급, 5회 틀리면 그 IP 10분 잠금). 프로필에서 **닉네임 변경 · 비밀번호 변경 · 복구 코드 재발급**(현재 비밀번호 확인). 같은 기기에선 마지막 닉네임 자동 채움. 옛 4자리 회원은 로그인 시 변경 안내. (이메일 인증은 보내는 메일 계정이 없어 제외 — 구현은 커밋 f132173에 보관)
  - **🏆 메인 화면 리더보드** — 시작 화면 왼쪽 패널에 상위 10명(🥇🥈🥉·티어 기물·전적·레이팅)과 내 순위, [전체 순위 · 티어 · 규칙 →] 버튼.
  - **👥 로비 게임 만들기** — 사설 방을 만들고 좌측 **"🔗 친구 초대 링크"** 를 [복사]해 친구에게 전달.
    친구가 같은 와이파이에서 그 링크(`http://192.168.x.x:7555/#방코드`)로 접속하면 흑(위), 나는 백(아래).
  - **🤝 친구에게 도전** — 친구가 준 **방 코드**를 입력해 그 방에 참가.
  - **💻 컴퓨터와 대국** — AI 봇과 실제 대국(사람=백, 봇=흑). **난이도 🟢쉬움 / 🟡보통 / 🔴어려움**.
  - **🎯 혼자 연습** — 핫시트(한 화면에서 양쪽 번갈아 조작). **[🌫 안개 걷힘]** 토글로 안개 on/off.
  - **🎓 튜토리얼** — 카드 5장으로 규칙을 익히는 온보딩(맵·시야·기물·킹·부쉬/숲). **첫 방문 시 자동**으로 뜬다.
  - **⚙️ 설정** — 🔊효과음 · 🎵**배경음악**(합성 앰비언트) · 🔉볼륨 · 🎨다크/화이트 테마 · 👁**색약 모드**(이동·착탄을 청록/주황으로) · 📖기물 설명. (설정은 브라우저에 저장돼 유지)
- 초대 링크(`#방코드`)로 들어오면 메뉴를 건너뛰고 **곧장 그 방**으로 입장한다.

> 포트는 `config.py`의 `PORT`(현재 7555). **추가 패키지 설치 불필요** — 서버·게임은 파이썬
> 표준 라이브러리만으로 돈다. (테스트만 `pytest` 필요)

## 방(room) 시스템

- 여러 쌍이 각자 다른 방에서 동시에 플레이(방코드로 구분).
- **재접속**: 창을 닫거나 새로고침해도 같은 링크로 들어가면 원래 자리로 복귀.
- **재대결**: 결과 화면의 **[↻ 재대결]** 또는 좌측 **[↻ 새 게임 / 재대결]**.
- **기권 / 나가기**: 게임 중 **[🏳 기권]**(상대 승리) · **[🚪 나가기]**(방 떠나기).
- **무한게임 방지**: `TURN_LIMIT`(기본 200)턴까지 승부가 안 나면 무승부.
- 상대가 15초+ 무응답이면 그 자리는 새 접속자가 회수 가능. **30분(`ROOM_TTL`) 방치된 방은 자동 삭제**.

## 조작

- 내 기물을 **클릭 또는 드래그**해서 이동. **초록 점** = 갈 수 있는 빈 칸, **초록 링** = 잡을 수 있는 적. **선택 취소**는 빈 칸 좌클릭.
- **비숍(저격)·전차(돌파)·퀸(스캔)** 선택 시 하단 **능력 버튼** → 표시된 범위·표적을 클릭
  (사거리 = **하늘색**, 착탄 = **빨강**, 스캔 범위 = **보라**).
  - **비숍 저격**: 반경 5 **사거리 원**이 옅은 하늘색으로 항상 뜨고, 그중 **지금 보이는 적**만
    **진한 하늘색 + 밝은 링**으로 강조(클릭해 저격). 사거리 안이라도 안 보이는 적은 못 맞힘.
- **턴 표시**: 내 차례엔 보드 테두리가 **초록으로 맥동** + 상단 배너, 내 차례로 바뀔 때 "딩" 소리.
- **우클릭 주석(리체스식)**: 우클릭 **드래그 = 화살표** / 제자리 = **원**, **좌클릭으로 전부 지움**(작전 메모, 본인 화면에만).
- 하단 **코치 문구**가 지금 할 일을 안내. **🔊 소리** on/off 토글.
- 상단 **[❔규칙]·[⚙설정]** — 규칙 모달 / 효과음·볼륨·테마·기물설명(게임 중에도 열림, [뒤로]로 복귀).

## 규칙 요약

- 맵 **12×12**, 기물 **16개**: 룩2·나이트2·비숍2·**퀸1**·폰8·킹1 (표준 체스 편성).
- **배치 단계 70초**: 자기 진영 3줄(맨 위/맨 아래 3줄) 안에 드래그/클릭으로 배치 → **[준비 완료]**.
  **자리 교환**: 기물을 내 다른 기물 위에 놓거나, 기물을 선택한 뒤 다른 기물을 탭/클릭하면 두 기물의 위치가 바뀐다(⇄).
  **부쉬에도 배치 가능**(숲·강에는 불가). 부쉬는 롤식: 안의 기물은 밖에서 안 보이지만, 붙어 있는 같은 덤불에 들어가면 서로 보인다. `[↩ 기본 포진] / [🎲 무작위 배치]` 버튼 제공.
- **시야(안개)** 반경: 폰1 · 비숍1 · 룩1 · **퀸1** · **나이트2** · **킹3(정찰)**. **숲이 시야를 막음**(LOS).
- **폰**: 첫수 2칸 · 앞·좌·우·앞대각 1칸 · **후퇴 불가**. 끝줄 도달 시 **승격**(전차/나이트/비숍 중 선택).
- **나이트**: 체스와 동일(근접 정찰의 핵심).
- **킹**: 8방향 1칸 이동(**시야만 3칸**). 목숨 1.
- **비숍(저격수)**: 대각 2칸 이동 / **단일 타일 저격**(사거리 5) — **내 팀 시야에 든 적만 명중**
  (숲 뒤·부쉬·안개에 숨으면 못 맞힘). **쏘면 내 위치가 노출**.
- **룩(전차)**: 상하좌우 2칸 이동 / **돌파 사격**(**십자 4칸** 관통, 숲에 막힘). **쏘면 내 위치가 노출**.
- **퀸(정찰)**: 8방향 2칸 이동 / **스캔**(맨해튼 6 안 한 지점 기준 **2×2를 ~2턴 감시**해 안개·부쉬 속 적을 노출. **감시 지역은 상대도 파랗게 봄**, 단 **퀸 위치는 노출되지 않음**).
- **킹 목숨 1** — 한 번 맞으면 처치, 그쪽이 승리. 기권해도 상대 승리.
- **턴 제한 30초(⏳)** — 한 턴을 30초 넘기면 패배가 아니라 **그 턴은 자동으로 상대에게 넘어간다**(기물 그대로).
  **연속 3회(=1분 30초) 미행동**하면 **상대 자동 승리**. 자기 수를 두면 카운터는 리셋. (솔로·봇 차례엔 미적용)
  플레이 중 접속이 **90초 이상 끊기면 자동 기권**(서버가 5초마다 점검, 폴링 없어도 진행).
- **랭크 매칭**(메인 화면 맨 위 카드, 로그인 회원 전용): 레이팅 차 ±100에서 10초마다 +50(최대 ±400), 60초 뒤엔 무제한으로
  자동 매칭 → **수락 창(A(레이팅) vs B(레이팅), 15초)** → 둘 다 수락하면 서버가 두 사람을 앉힌 방을 만들어 자동 입장(색 무작위) → 레이팅전.
  거절하거나 시간 안에 수락하지 않은 쪽은 대기열에서 빠지고 상대는 다시 대기. 같은 계정끼리는 안 붙고, 30초 넘으면 컴퓨터 대국 제안.
  **수락한 순간부터 승부**: 배치 단계라도 [나가기]는 기권 패배(확인창)이며 레이팅이 내려간다. 접속이 90초 넘게 끊겨도 기권 처리.
  **재대결은 둘 다 눌러야 시작**(사람끼리): 종료 화면에서 [재대결 제안] → 상대 화면에 [수락]/[거절]. 끝난 뒤 [나가기]는 결과 그대로(추가 변동 없음).
- **플레이어 패널**(게임 화면 오른쪽, 리체스식): 위=상대·아래=나. 티어 기물 아바타, 이름(레이팅), 잡은 기물 아이콘과 우세(+N), 병력 수,
  차례인 쪽에 30초 턴 시계(6초 이하 빨강). 아래에 ⏱ 경과 시간(전투 시작부터, 종료 시 고정)과 턴 수.
- **레이팅전은 랭크 매칭 + 컴퓨터 대국만**. 로비(친구) 대전·혼자 연습·게스트 대국은 레이팅에 반영되지 않는다(친구끼리 점수 주고받기 방지).
  **컴퓨터 대국은 이기면 오르고 져도 내려가지 않음**(`BOT_NO_LOSS`), 대신 난이도별 상한(`BOT_GAIN_CAP`=컴퓨터 레이팅+200 → 쉬움 1000·보통 1200·어려움 1500)까지만 오른다.
  레이팅이 **내려가는 건 랭크 매칭에서 질 때뿐**. 봇 방 시작 로그에 '이기면 +N, 져도 내려가지 않아요'가 표시된다.
- **맵은 방마다 새로 생성**(펄린 노이즈 숲 + 대칭 부쉬, 위아래 숲 개수 동일). 방 태그에 `🗺 맵 #시드`가 뜬다.
  `config.PERLIN_SEED`를 정수로 고정하면 모든 방이 같은 맵, `NEW_MAP_ON_REMATCH`로 재대결 시 새 맵 여부, `EXTRA_TERRAIN='both'`면 강+부쉬.

> **정보전이 핵심**: 저격하려면 먼저 봐야 하고(킹 시야3·나이트로 정찰), 공격하면 노출된다(노출은 **그 기물 칸만** 보임 — 주변 칸이나 숲 뒤가 밝아지진 않음).
> 비숍=본 것을 처형 / 룩=광역 수색·제압 / **퀸=원거리 스캔 정찰** / 나이트=몸으로 하는 근접 정찰.

## 지형

- 🌲 **숲**: 시야·이동·사격을 **모두 차단**.
- 🌿 **부쉬(매복지)**: 들어갈 수 있다. **속의 기물은 밖에서 보이지 않음**(인접·시야로도 안 보임). 단 **붙어 있는 같은 덤불에 들어가면 그 안의 기물은 서로 보이고 저격도 가능**(롤의 부쉬처럼, v1.48). 홀로 떨어진 부쉬가 가장 안전한 은신처.
  확인하려면 **부쉬로 들어가 잡거나 룩 돌파사격으로 수색**. 내 기물이 부쉬에 있으면 **반투명**으로 표시.
- 🌊 **강**(옵션, 기본 off): 이동·배치만 차단, **시야·사격은 통과**. 나루터로만 도하.
- 맵은 **펄린 노이즈로 자동 생성**(서버 켤 때마다 랜덤), 대칭 방식 `balanced`(공정+다양).

## 맵 / 밸런스 수정하기 (`config.py` 한 파일)

모든 튜닝값은 **`config.py`** 에 모여 있다. 수정 후 **서버 재시작**(Ctrl+C → `python server.py`).

### 지형

- `USE_PERLIN = True` → 숲을 노이즈로 자동 생성. `False` → `MAP_ROWS` 수동 지도(`#`=숲, `.`=빈 땅) 사용.
- 맨 위/아래 각 2줄(스폰 구역)에는 숲이 생기지 않음.
- `EXTRA_TERRAIN`: `'bush'`(부쉬) / `'river'`(강) / `'none'`. `BUSH_COUNT`로 부쉬 수 조절.
- `MAP_SYMMETRY`: `rotational`(180°대칭) · `mirror`(상하거울) · `balanced`(비대칭+공정, 추천) · `free`(완전 랜덤).

### 숫자 밸런스

| 값 | 의미 |
|---|---|
| `VISION` | 기물별 시야 반경 (나이트3 · 킹3, 나머지 1) |
| `KING_LIVES` | 킹 목숨 |
| `ROOK_RANGE` | 룩 **이동** 최대 칸 |
| `ROOK_FIRE` | 룩 **돌파사격**(십자) 최대 칸 |
| `BISHOP_MOVE` | 비숍 대각 이동 최대 |
| `BISHOP_RANGE` | 비숍 **저격** 사거리 |
| `QUEEN_MOVE` | 퀸 8방향 이동 최대 |
| `SCAN_RANGE` | 퀸 **스캔** 캐스트 사거리(맨해튼) |
| `SCAN_DUR` | 스캔 지역 감시 지속(턴) |
| `MUZZLE` | 공격 후 위치 노출 지속(턴) |
| `SETUP_SECONDS` | 배치 제한 시간(초) |
| `TURN_SECONDS` | 한 턴 제한(초). 초과 시 자동으로 상대 턴으로 |
| `MAX_MISSES` | 연속 미행동 이 횟수면 상대 자동 승리 |
| `TURN_LIMIT` | 무승부 턴 한도 |
| `ROOM_TTL` | 빈 방 자동 삭제 시간(초) |
| `BOT_HARD_BUDGET` | 어려움 봇 한 수 탐색 시간(초) |
| `BOT_EASY_BLUNDER` | 쉬움 봇 무작위 실수 확률(0~1) |

## 파일 구성 (역할별 분리)

- **`config.py`** — 모든 설정값(포트·맵·밸런스·타이머). **튜닝은 여기만.**
- **`game_map.py`** — 지형: 펄린 숲/부쉬/강 생성, 시야 차단(LOS).
- **`pieces.py`** — 규칙 엔진: 행마·저격·돌파사격·승격·킬로그·안개 뷰(`player_view`).
- **`bot.py`** — AI 봇: 자기 안개 시야만 보고 판단(치트 없음). **숨은 왕을 능동 사냥** — 미확인 적진(특히 부쉬)을 후보로 두고 진입·정찰로 좁혀 감 + 킹 방어(은신·수비대·선제 대피). **난이도 3단계**: 쉬움(사냥X·잦은 실수) / 보통(수색+가벼운 미니맥스+가끔 실수) / 어려움(공격적 수색+깊은 미니맥스+알파-베타·반복심화, 실수 없음). *봇끼리 대국으로 강도 보정.*
- **`server.py`** — 서버/네트워크: 방·재접속·봇 구동·HTTP. 규칙은 pieces에 위임.
- **`client.html`** — 화면 뼈대(HTML 구조만).
- **`style.css`** — 스타일 + **디자인 토큰**. **색·글꼴·여백은 맨 위 `:root` 변수만 고치면 전체에 반영.**
- **`game.js`** — 화면 로직(보드 렌더·조작·드래그·통신·이펙트·킬로그).
- **`sound.js`** — 효과음 + **배경음악**(Web Audio로 실시간 합성, 오디오 파일 없음). 소리 수정은 여기.
- `img/` — Lichess(cburnett) 체스 기물 SVG.
- `test_fogchess.py` — 규칙 엔진 pytest.
- `패치노트.txt` — 변경 이력(버전·날짜별).

의존 방향: `config` ← `game_map` ← `pieces` ← `{bot, server}` (한 방향, 순환 없음).

## 테스트

```bash
python -m pytest
```

행마·저격·돌파사격·**부쉬 은폐**·**퀸 스캔**·승격·기권·봇(난이도) 판단을 회귀 테스트로 고정한다.

## 먼 곳의 친구와 하려면 (다른 와이파이·인터넷 어디서나)

같은 와이파이가 아니면 LAN 주소로는 안 된다. **cloudflared 빠른 터널**(무료·계정 불필요)로
내 서버를 잠깐 인터넷에 공개하면, 친구가 어디서든 접속할 수 있다.

1. **cloudflared 설치**(한 번만):
   ```bash
   winget install --id Cloudflare.cloudflared
   ```
   (또는 https://github.com/cloudflare/cloudflared/releases 에서 `cloudflared.exe` 다운로드)
2. **서버를 공유 모드로 실행**:
   ```bash
   python server.py --share
   ```
   콘솔에 `https://<무작위>.trycloudflare.com` **공개 주소**가 뜬다.
3. **나도 그 공개 주소로 접속** → **[로비 게임 만들기]** → 화면의 **"친구 초대 링크"**(자동으로
   그 공개 주소로 생성됨)를 친구에게 전달. 친구가 그 링크로 들어오면 대전 시작.

> 원리: 초대 링크는 **"내가 이 페이지를 연 바로 그 주소"**를 따라간다(`game.js`의 `inviteBase`).
> 그래서 LAN IP로 열면 LAN 링크, 터널 주소로 열면 터널 링크가 된다 — 별도 설정이 필요 없다.
> `cloudflared` 없이 `--share` 하면 설치 방법을 안내한다. 서버를 끄면 공개 주소도 사라진다(임시 공유).

## 인터넷에 상시 배포 (내 PC 없이 아무나 접속)

호스팅에 올리면 **고정 공개 주소**가 생겨, 인터넷만 되면 누구나 접속해 방 코드로 함께
플레이할 수 있다(로그인 없음). 배포 준비는 이미 되어 있다 — `config.py`가 호스트의 `PORT`
환경변수를 읽고, 서버는 표준 라이브러리만 쓰므로 빌드가 가볍다. 게임 상태는 메모리에 있으니
**단일 인스턴스**로 운영(스케일 아웃 X), 서비스가 재시작되면 진행 중이던 방은 사라진다.

### Fly.io (추천 — 빠른 시작/항상 켜둠 가능, 신용카드 필요)

Docker로 도쿄 리전에 배포 → `https://<앱이름>.fly.dev`. 준비 파일: `Dockerfile`·`fly.toml`·`.dockerignore`.

1. flyctl 설치: PowerShell에서
   ```powershell
   pwsh -Command "iwr https://fly.io/install.ps1 -useb | iex"
   ```
2. 가입/로그인(카드 등록 필요): `fly auth signup` (또는 `fly auth login`)
3. 이 폴더에서 배포:
   ```bash
   fly launch    # Dockerfile·fly.toml 감지, 앱 이름/리전 확인 → 첫 배포
   ```
   (이후 코드 바꾸면 `fly deploy` 로 재배포.) 나온 `https://<이름>.fly.dev` 로 접속.
4. **계정·레이팅 DB 보존(볼륨)** — `fly.toml`에 `[mounts]`(볼륨 `fogchess_data` → `/data`)와
   `[env] FOG_DB=/data/fogchess.db`가 들어 있어, 배포하면 `fogchess.db`가 볼륨에 생긴다(재배포·재시작에도 유지).
   볼륨은 **머신 1대에만** 붙으므로 머신을 1대로 유지한다:
   ```bash
   fly launch --ha=false           # 처음: 앱 생성 + [mounts] 보고 볼륨 자동 생성(물어보면 yes)
   fly volumes list                # 볼륨이 안 보이면 직접: fly volumes create fogchess_data --region nrt --size 1
   fly deploy --ha=false           # 이후 재배포도 1대로
   fly ssh console -C "ls -l /data"   # fogchess.db 확인
   ```
   > 볼륨 없이 배포하면 마운트 실패로 머신이 안 뜬다. 볼륨을 2개 만들면(머신 2대) DB가 둘로 갈라지니 반드시 `--ha=false`.
- `fly.toml`의 `min_machines_running = 0` = 유휴 시 자동 정지(비용↓, 접속 시 수초 내 자동 시작),
  `1` = 항상 켜둠(첫 로딩도 없음, 비용 조금↑). 이 작은 앱은 정지형이면 월 몇 백원~수천 원 수준.

### Render (무료, 카드 없음 — 대신 첫 로딩 느림)

`https://<이름>.onrender.com`. 준비 파일: `render.yaml`·`Procfile`·`requirements.txt`.

1. https://render.com 가입(GitHub 로그인).
2. **New + → Blueprint** → 이 저장소 선택 → `render.yaml` 자동 인식 → **Apply**.
   (수동: **New Web Service** → repo → Runtime **Python** → Start `python server.py` → Plan **Free**.)
3. 나온 주소로 접속 → [로비 게임 만들기] → 초대 링크 공유.

> Render 무료 티어는 15분 미접속 시 잠들어 다음 첫 접속이 ~1분 걸린다(그 뒤엔 빠름).
> Fly.io 정지형은 다시 뜨는 데 보통 몇 초라 더 빠르다.


## 개발자 피드백 읽기

플레이어가 왼쪽 레일 **[💬 피드백]**으로 보낸 내용은 `fogchess.db`의 `feedback` 테이블에 쌓인다(분류·내용·닉네임 또는 익명·방 코드·브라우저).
- 로컬/서버 콘솔에서: `python accounts.py feedback` (최근 50개, 숫자를 붙이면 개수 조정)
- Fly.io에서: `fly ssh console -C "python accounts.py feedback"`
- **관리자 페이지** `https://<주소>/admin` → 비밀번호(`FOG_ADMIN_KEY` 시크릿) 입력 → 피드백 카드(처리됨 ✓ / 삭제 🗑, 처리된 것 보기 토글)와 회원·레이팅 표. 틀린 비밀번호 5회면 그 IP는 10분 잠금. CLI: `python accounts.py feedback [limit] [all]` · `python accounts.py users` (배포 서버는 `fly ssh console -a fogchess -C "python accounts.py feedback"`).
- 도배 방지: 같은 IP는 10초에 한 번, 내용은 3~1000자.
