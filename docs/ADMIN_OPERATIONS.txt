안개전장 관리자 운영 기능 · 2026-10-24

진입: 로비 → 설정 · 소식 → 게임 설정 → 맨 아래 버전 표시를 5초 안에 5번 누르기
설정을 닫거나 5초가 지나면 누른 횟수가 초기화됩니다. 로그인 창만 열며 관리자 키 인증은 그대로입니다.
이 진입 경로는 Fly.io 릴리스 30에 배포됐습니다. 운영 브라우저에서 4회 클릭은 유지, 5회 클릭은 관리자 키 입력창 표시를 확인했습니다.
로그인 입력란의 보기/숨기기로 입력을 확인할 수 있습니다. 기본 상태는 숨김입니다.
키 불일치(403), 인증 시도 제한, 연결 실패는 각각 다른 안내를 표시합니다. 기존 키 값은 변경하지 않았습니다.
로그인 안내 수정과 보기 버튼은 Fly.io 릴리스 31에 반영됐습니다. 실제 운영 브라우저에서 기존 키 인증 및 현황 로딩을 확인했습니다.
기존 관리자 키로 로그인합니다. 키는 HTTP 헤더로만 전송되며 팝업을 닫거나 로그아웃하면 지웁니다.
start-dev.ps1은 환경변수에 키가 없을 때 이 PC의 .dev-data/security/admin-key.dpapi를 읽어 로컬 서버 프로세스에만 전달합니다. 저장된 키를 바꾸지 않습니다.

운영 메뉴
1. 현황: 최근 90초 활동한 로그인 회원, 진행 중 대국, 매칭 대기, 미처리 제보, 정산 대기, 오류 확인. 새로고침 시 갱신.
2. 유저 · 제재: 닉네임/ID 검색, 계정/최근 전적/조치 이력, 경고, 채팅·새 대국 제한, 계정 정지(1~30일), 해제와 사유.
3. 신고 · 피드백: 분류, 우선순위, 처리 상태, 내부 메모, 연결된 종료 리플레이. 숨김은 논리 삭제로 감사 이력을 보존.
4. 대국 · 정산: 종료 대국, 저장 기보, 채팅, 정산 대기 재처리, 검토 완료, 이 대국 레이팅 증감 정정.
5. 공지 · 점검: 초안/게시/게시 해제, 새 대국 중단·재개. 진행 중 대국/좌석 재접속은 유지. 종료 후 재대국은 중단 대상.
6. 밸런스: 실제 종료 대국의 선후공 승률, 시작 레이팅 구간, 능력 사용/포획 발생률. 업데이트 이후 수집한 기록만 사용.
7. 작업 기록: 작업자, 시각, 대상, 사유, 변경 전/후. 읽기 전용 API, 변경·삭제 버튼 없음.

플레이어 동선
- 로비 설정 · 소식 → 공지 · 점검 안내: 현재 게시된 공지.
- 로비 내 계정 → 제재 안내 · 이의제기: 본인 제재와 접수 상태.
- 정지 중에도 지원용 로그인으로 이의제기를 제출할 수 있습니다. 지원용 토큰은 일반 게임/프로필 변경 권한으로 사용 불가.
- 종료 리플레이 → 이 대국 신고: 해당 대국의 로그인 참가자만 상대 회원/현재 수순을 연결해 접수. 한 시간 최대 5건.
- 이의 수용 표시와 제재 해제는 별도 조치입니다. 수용 후 필요하면 유저 · 제재에서 해제합니다.

정산/데이터
- admin_ops.py: 기존 계정 SQLite DB에 추가 테이블/컬럼을 이식. 기존 회원·점수·기보를 삭제하지 않음.
- 모든 새 관리 변경은 requestId 기반 재시도 중복 방지, 트랜잭션 내 감사 기록, 수정 버전 충돌 확인(제보/공지/대국).
- 레이팅 정정은 연결된 종료 대국만 지원. 현재 점수와 이후 전적/정산 영수증도 차이만큼 보정. 500점 하한 검증. 승패 수는 변경하지 않음.
- 정산 대기는 원래 요청을 DB에 보존해 서버 재시작 뒤에도 재처리. 완료된 정산의 재처리 중복 반영 방지.
- 이전 기보는 최근 30개 읽기 경로 제공. 과거 대국에 임의의 관리 정산 연결이나 밸런스 표본을 만들지 않음.
- 유저/제보/감사 목록은 100개, 대국은 50개 단위 페이지. 회원 상세는 최근 전적 20개, 제재 100개. 오류 최근 50개. 공지 최근 30개.
- 관리자 키는 기존 공용 키 권한입니다. 로그인된 회원이 있으면 감사 기록에 검증된 회원 ID·이름을 함께 기록하고, 없으면 공용 키 관리자라고 명시.
- 제재는 해당 계정과 연결된 좌석에 적용됩니다. 기기/IP 단위 제재가 아니며 게스트 계정을 동일 인물로 추정하지 않습니다.
- 실시간 안개 속 보드는 관리 API에서 제공하지 않음. 관리자 증거 열기는 종료된 저장 리플레이에 한정.
- 내부 메모/자격 증명/다른 회원 제재는 본인 지원 API로 내보내지 않음. 오류에는 경로·예외 종류만 저장.
- 백업 모니터링 연동은 없음. 운영 현황에서 미연결로 표시. 실제 백업 자동화 기능을 가장하지 않음.
