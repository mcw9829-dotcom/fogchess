대전 채팅
- 사이드바 이동 기록 아래. 배치 중/대국 중/결과 화면에서 사용.
- Enter 또는 전송 버튼. 한글 200자, 1초 전송 간격, 최근 80개 유지.
- 접었을 때 상대 새 메시지 개수 표시. 텍스트만 표시하며 마크업 실행 없음.
- 같은 방 재대결은 채팅 유지. 다른 방 입장 시 초기화.
- 관전자/봇전/혼자 연습/리플레이에는 채팅 없음. DB에는 저장하지 않음.

랭크 2선승 시리즈
- 경기 종료 후 상대에게 신청, 양쪽 동의하면 다음 경기 배치 시작.
- 먼저 2승하면 재대결 종료. 1승 1패면 최종전.
- 무승부는 승수에 포함하지 않으며 재대결 가능. 총 경기 수 제한 없음.
- 기존대로 각 경기 전적과 레이팅을 정산. 시리즈 종료 보너스/추가 감점 없음.
- 친구방/봇전/솔로의 기존 재시작 정책은 유지.
- 시리즈는 방 단위 서버 메모리 상태이며 재접속 시 유지, 서버 재시작 시 사라짐.

Windows 한글 입력 / 개발 엔진 선택 (2026-10-21)
- 현재 Steam 4.7.2에는 Microsoft 한국어 IME가 이전 음절을 덮어쓰는 공식 회귀 버그가 있음.
  https://github.com/godotengine/godot/issues/123269
- 원인: Windows 메시지 큐 필터링. 수정 PR #123274는 IME 활성 중 전체 메시지를 처리함.
  https://github.com/godotengine/godot/pull/123274
- 4.7.3 브랜치에 수정이 반영됐지만 확인 시 정식 배포본은 없음. 4.8은 베타이므로 사용하지 않음.
- 프로젝트 전용 4.7.1 안정판을 .dev-data/tools/godot-4.7.1/에 설치해 회귀 버그를 회피.
  재설치: python setup_godot_runtime.py (공식 배포 파일 SHA512 검증).
- 실행: ./start-dev.ps1 -Play (게임), ./start-dev.ps1 (에디터).
  Steam으로 직접 실행하면 여전히 4.7.2이므로 같은 문제가 날 수 있음.
- godot_runtime.py는 GODOT_EXE 명시값 → 프로젝트 전용 엔진 → 기본 설치 순서로 선택.
- 4.7.1에서는 원래 채팅 입력칸을 사용하고 별도 한글 입력 버튼은 숨김.
  4.7.2로 직접 실행하는 경우에만 기존 별도 입력창을 임시 대안으로 유지.
- 웹은 Windows IME 메시지 처리의 영향을 받지 않음. 기존 4.7.2 엔진/웹 템플릿으로 빌드 유지.
- 자동 검증은 채팅 송수신, 초안/커서 보존 및 게임 호환성 검사. 실제 한글 조합 검증과는 다름.
  실제 입력 최종 확인: 안녕 / 안녕 세상아 / 가나다, 백스페이스, 중간 편집, Enter 전송.
- 사용자의 PC 사용 중단을 피하기 위해 UI 자동 조작을 멈춤. 실제 IME 재확인은 아직 남아 있음.
- Steam 설치/Windows IME 설정/실행 중 대국은 변경하지 않음. Fly.io 배포 없음.
- 검증 결과: 4.7.1 주 게임/채팅 통합 검사 실패 0, 관전 17항목 및 리플레이 25항목 통과.
- 관전 검사 종료 시 ObjectDB 2개 누수 경고는 남음(기능 검사는 통과).
- 로컬 웹 재빌드 및 웹 호스트 7개 검사 통과.
