Fog Chess QA 반영 — 2026-10-20

승인된 방향
- 기존 30초 턴 유지. 초보자용 연장 시간 없음.
- 기물 주변 행동 메뉴, 펼침 애니메이션, 흰색 호버 유지.
- 잔여 상대 기물 추정 표시를 '잡은 기물'로 교체.
  폰: 작은 아이콘 × 개수. 나이트·비숍·룩·퀸·킹: 큰 아이콘을 개별 표시.
  아군 오폭은 전리품에 넣지 않음.
- 킬로그: 나/적, 공격 기물, 처치 방식, 희생 기물을 한 줄로 표시.
  CS2의 간결한 처치 스트립 구조를 참고하며 외부 이미지/자산은 사용하지 않음.
- 킬로그/전리품 아래에 내 행동 기록 표시. 상대의 숨은 출발/도착 위치는 비공개.
- 랭크 매칭과 랭크 재대결의 숲·부쉬·강은 180도 회전 대칭.

확정한 규칙
- 승격 대기 중 일반 이동·저격·돌파·스캔 금지.
- 선택 시간이 끝나면 전차로 자동 승격하고 턴 종료.
- 이동 후보는 현재 관측 가능한 기물만으로 계산.
- 실제 이동 도중 숨은 적을 만나면 그 칸에서 포획하고 정지, 한 턴 소비.
  나이트의 점프는 경유 칸과 충돌하지 않음.
- 봇의 판단·탐색 상태에서 현재 보이지 않는 적의 실제 위치 제거.
  기억/정찰 데이터는 유지하지만 이를 실제 위치 정답으로 사용하지 않음.

UI 개선
- 타이머에 미행동 누적·10초 이하 경고 표시.
- 자기 기물의 발사 후 위치 노출 상태와 남은 턴 표시.
- 승격 창은 내 차례에만 표시. 그림 버튼과 최초 키보드 포커스 제공.
  닫기 후 즉시 다시 뜨는 동작을 없애기 위해 승격 선택 전 닫기는 제공하지 않음.
- 터치에서도 쓸 수 있는 선택 취소 버튼 제공.
- 색약 모드는 이동·능력 범위·스캔·이펙트까지 반영, 범위의 모양도 구분.
- 튜토리얼은 실전과 같은 기물 주변 행동 메뉴 사용.
- 매칭 중 초 단위 숫자 갱신만으로 수락/거절 버튼을 재생성하지 않음.

관전/리플레이 설계 (관전은 후속 구현 완료: SPECTATING 안내 참조)
- 관전: 전체 보드 공개, 실제 진행보다 180초 늦은 상태만 전달.
  브라우저에서 시간을 늦추는 것이 아니라 서버가 과거 상태만 전송해야 함.
- 리플레이: 대국 종료 후 전체 기보를 재생. 진행 중에는 전체 기록 비공개.
- 일반 체스 PGN만으로는 12x12 보드, 임의 배치, 지형, 스캔·저격·돌파를
  정확히 재현할 수 없음. Fog Chess 확장 기보가 필요.
- 기보에는 규칙 버전, 지형 전체 배치, 초기 기물 배치, 행동 순서와 시간,
  이동 실제 도착점, 능력 표적, 승격, 시간 초과, 종료 원인을 기록해야 함.
- 이번에는 서버에 구조화된 행동 기록(notation)과 시점별 이동 기록을 추가.
  이것만으로 완전한 리플레이가 되지는 않음. 재생 화면·영구 보관·내보내기·
  초기 상태/시간 초과 기록은 리플레이 작업 때 구현할 대상.
- 상대 잔여 기물의 정확한 종류별 구성은 공개하지 않음.

운영
- 개발 작업 폴더에만 적용. Fly.io 배포·운영 DB 변경 없음.
- 실행 중인 Python 프로세스는 자동으로 새 코드를 읽지 않으므로 QA 서버는
  진행 중인 대국이 끝난 뒤 재시작해야 새 규칙이 적용됨.
- 기존 QA 보고서와 Kiro의 QA 스크립트는 수정하지 않음.

검증 결과
- Python 회귀: 111개 + 하위 검사 12개 통과.
- Godot 실제 렌더링 통합: 186개 통과.
- 이동/이펙트 회귀: 14개 통과.
- PC 1280x720, 모바일 폭 390x844 캡처 확인(실제 모바일 기기 검증 아님).
- 로컬 Web 내보내기 완료. Fly.io 배포 없음.
- 킬로그는 최근 5건 표시, 잡은 기물 합계는 전체 누적.
