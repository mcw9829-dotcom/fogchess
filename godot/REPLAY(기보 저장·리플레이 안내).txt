리플레이 — Godot 개발 버전

사용: 대국 종료 화면 → 기보 / 리플레이 보기.
다시 보기: 홈 → 리플레이 → 이 기기에서 확인한 종료 대국 선택(최근 100개).
이전 수 / 다음 수 / 자동 재생 / 일시 정지 / 닫기.
자동 재생은 1.5초 간격, 마지막 수에서 멈춤. 마지막에서 다시 누르면 처음부터 재생.
되돌리기는 보드·잡은 기물·킬로그·이동 기록을 같은 시점으로 복원.
재생 중 서버 폴링이나 게임 조작이 화면을 덮어쓰지 않음.

저장: 회원 DB와 별도인 replays.sqlite3. 기본 위치는 회원 DB와 같은 폴더.
개발 서버에서는 .dev-data/replays.sqlite3. FOG_REPLAY_DB 환경변수로 변경 가능.
게임 종료 즉시 저장, 방 삭제·서버 재시작 후에도 유지. 재대결은 별도 기보.
계정·기존 전적 DB의 스키마를 변경하지 않음. Fly.io 배포 없음.
기보 본문에 계정 세션/접속 토큰은 저장하지 않으며 접근 확인용 토큰 해시를 별도 보관.
참가자는 종료 즉시 열람, 그 외에는 종료 후 180초 지나야 공개.
이미 끝난 과거 대국의 기록을 소급 생성할 수는 없음.

형식: fogchess-replay-v1 (JSON을 압축해 SQLite에 저장).
12x12 보드, 지형, 초기 배치, 기물 ID/상태, 행동별 좌표/표적,
저격·돌파·스캔·승격·시간 초과·기권과 각 단계의 정확한 화면 기록.
일반 체스 PGN과 다른 전용 확장 기보. 현재 규칙 코드를 다시 실행하지 않고 저장된 장면을 재생하므로
향후 규칙이 바뀌어도 당시 위치·포획 결과를 유지한다.
진행 중 기보는 메모리에만 있고 서버 중단 시 복구 대상은 아님.
서버에는 종료 기보가 지속 저장되며, 홈 목록은 현재 기기에 저장된 열람 이력이다.

파일: replays.py, features/replay(기보 저장·수순 재생).gd
검증: test_replays.py, run_replay_smoke.py, tests/replay_smoke.gd
