수정 방법
  1. 기능에 맞는 features 파일에서 구현을 수정한다.
  2. 모듈은 app.<상태>로 공유 상태에 접근한다.
  3. 다른 기능 호출은 app._함수()를 통해 main의 연결 함수를 이용한다.
     이 연결은 기존 신호·비동기 호출·통합 테스트의 인터페이스를 유지한다.
  4. 기능 내부에만 쓰는 새 함수는 해당 모듈에 추가한다.
     외부에서 호출해야 하는 진입점에만 main 연결 함수를 추가한다.
  5. main의 연결 함수에는 게임 로직이나 화면 구현을 추가하지 않는다.
  6. app_state에는 공유 데이터/노드 참조만 두고 기능 구현은 넣지 않는다.
