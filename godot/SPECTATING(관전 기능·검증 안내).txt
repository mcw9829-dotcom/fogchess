관전 기능 (개발 버전, Fly.io 배포 안 함)

입장: 홈 → 대국 관전 → 기존 방 코드 입력.
플레이어 좌석을 사용하지 않으며, 없는 방 코드는 방을 만들지 않고 오류를 표시한다.
서버가 보관하는 기록에서 현재보다 180초 이상 지난 장면만 전송한다.
보드, 배치, 스캔, 킬로그, 양쪽 전리품, 이동 기록, 이름, 타이머, 승패 모두 같은 과거 시점이다.
기록이 아직 없으면 대기 시간과 가려진 보드만 전송한다.
이미 기록이 쌓인 방에 입장하면 바로 3분 전 장면을 보여준다.
재대결 시 새 맵도 3분 뒤에 반영된다.

관전자 수는 현재 접속 인원: 지연 대기자 포함, 플레이어·봇 제외.
명시적 나가기는 즉시 반영, 강제 종료·접속 끊김은 마지막 요청으로부터 10초 뒤 제외.
중복 토큰 재접속은 같은 1명으로 집계한다.
플레이어에게 0명도 표시하며, 첫 입장 알림과 인원 증가 강조 효과를 제공한다.
관전자는 기물 정보 확인, 보드 뒤집기, 나가기만 가능하고 모든 게임 액션은 서버에서도 차단한다.

서버: spectator.py (지연 기록·전체 보드·접속 인원), server.py (입장/퇴장·기록 시점·권한)
Godot: features/spectating(관전·지연 중계·관전자 수).gd
검증: test_spectator.py, run_watch_smoke.py, godot/tests/watch_smoke.gd
테스트 전용 시간 이동 API는 run_watch_smoke.py 안에만 존재한다.
기록은 현재 서버 프로세스 메모리에 있고 재시작 시 사라진다.
후속 리플레이의 영구 저장과 재생 UI 구현 완료. REPLAY 안내 참조.
회원 DB나 전적 스키마를 변경하지 않았다.

최종 검증: Python 회귀 117개 + 하위 검사 12개, Godot 관전 17개, 기존 Godot 186개 통과.
PC/모바일 폭 캡처 및 로컬 Web 내보내기 완료. 실제 모바일 기기 검증은 아님.
실행 중인 개발 서버는 자동 재로드되지 않으므로 대국 종료 후 재시작 필요.
